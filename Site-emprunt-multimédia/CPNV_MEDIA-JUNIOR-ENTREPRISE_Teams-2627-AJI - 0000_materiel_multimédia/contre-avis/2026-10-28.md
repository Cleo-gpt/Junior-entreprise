Contre-avis

1. Dire « pour la version TPI, c'est suffisant côté tables » est trompeur.
Les tables existent, mais materials est vide.
Le site TPI s'afficherait avec un catalogue vide.

2. Piège oublié : import_materials_from_excel.sql (Travail Mathieu/database) contient aussi USE cpnv_gestmat.
Importé tel quel, il redonne l'erreur #1044.

3. L'ordre d'import pour la version Mathieu est juste.
Le code de Mathieu recopie lui-même les produits dans materials, donc les réservations fonctionneront.

4. Le script d'inventaire n'a ni SET NAMES utf8mb4 ni transaction.
Dans phpMyAdmin, vérifier que le jeu de caractères est utf-8, sinon les accents seront abîmés.
Si l'import s'arrête, on peut le relancer : il commence par des DROP TABLE.

5. Le mot de passe admin est en clair dans le SQL, sur GitHub.
Le changer avant que le site soit accessible, pas après.
Vérifier aussi que user_roles a 2 lignes.

6. Mise en ligne trop survolée :
site servi depuis web/,
storage/ accessible en écriture,
mail en mode « log » dans config/app.php, donc aucun e-mail ne partira.
